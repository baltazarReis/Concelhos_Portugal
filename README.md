# Concelhos de Portugal

Quiz sobre os concelhos de Portugal

Link para o jogo: https://concelhos-portugal.vercel.app/


Informação sobre o jogo:
- O objetivo é selecionar no mapa o concelho que corresponde ao nome que aparece no canto superior direito.

- É possível selecionar apenas um ou mais distritos de modo a treinar aqueles de que se tem menos conhecimento.

- É possível, quando não se tem ideia nenhuma da localização do concelho, abrir um painel de informação com
  imagens e algumas informações, nomeadamente localização, sobre o concelho de modo a aprender mais sobre este
  e facilitar a memorização do distrito a que pertence e posição no distrito.
  
- O melhor jogo é guardado e é possível compará-lo com o jogo acabado de fazer para ver se e onde houve melhorias.

- É possível consultar a informação adicional para o concelho sem detrimento para a pontuação após a jogada desse
  concelho, isto é, se o acertar ou se o passar à frente, ou mesmo após acabar o jogo. 
  (Através de fazer duplo clique no concelho que se quer consultar)
