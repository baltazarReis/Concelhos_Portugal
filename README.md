# Concelhos de Portugal

Quiz sobre os concelhos de Portugal

Link para o jogo: https://concelhos-portugal.vercel.app/


Informação sobre o jogo:
- O objetivo é selecionar no mapa o concelho que corresponde ao nome que aparece no canto superior direito.

- No menu inicial é possível selecionar apenas um ou mais distritos de modo a treinar aqueles de que se tem menos conhecimento.

- É possível, quando não se tem ideia nenhuma da localização do concelho, abrir um painel de informação com imagens e algumas
  informações, nomeadamente localização, sobre o concelho de modo a aprender mais sobre este e facilitar a memorização da posição do concelho.
  
- O melhor jogo é guardado e é possível, no painel de resumo do jogo, compará-lo com o jogo acabado de fazer para ver se e onde houve
  melhorias.

- É possível selecionar de forma imediata os piores x distritos (em termos de percentagem de acertos nesse distrito) no menu inicial, na aba
  de seleção de distritos. (Apenas se houver um recorde guardado claro)

- É possível consultar a informação adicional para o concelho sem detrimento para a pontuação após a jogada desse
  concelho, isto é, se o acertar ou se o passar à frente, ou mesmo após acabar o jogo. 
  (Através de fazer duplo clique no concelho que se quer consultar)
